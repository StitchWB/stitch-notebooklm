# Stitch NotebookLM

Open-core **service plugin** for [Stitch Manager](https://github.com/StitchWB/Stitch-Manager):
Google NotebookLM integration — list/create notebooks, ask questions against a notebook, and
generate Audio Overviews.

- **Kind:** `service` (plugin id `stitch-notebooklm`, service `notebooklm`)
- **Runtime:** spawned by the Stitch `ServicePluginHost` as `python -m stitch_notebooklm`, speaks
  JSON-RPC 2.0 (vendored `RpcPluginServer`)
- **Self-contained:** no `stitch_backend` imports. Calls the real Google NotebookLM API when
  cookies are provided; without cookies it degrades gracefully to local SQLite storage.

## Commands

`list_notebooks`, `create_notebook`, `ask`, `generate_audio`.

## Layout

```
plugin.json                  manifest (schema v2, declarative UI + i18n + commands)
stitch_notebooklm/
  __main__.py                JSON-RPC entry point (RpcPluginServer)
  service.py                 cookie conversion + NotebookLM client factory
  storage.py                 local SQLite fallback store
  _vendor/rpc_server.py      vendored RpcPluginServer (regenerated by stitch_plugin_tools; do not edit)
```

## Development

```bash
pip install ruff
ruff check .
```

Integration tests for this plugin live in the private Stitch monorepo (they need the Stitch SDK
and plugin host). This repo's CI runs lint + compile checks; the monorepo runs the full
plugin-vs-core integration suite against the mirrored copy.

## Distribution

This plugin is **signed and distributed via the Stitch gated server** — the signing key lives in
the private hub, never in this repo. Released packages are assembled from this source, signed in
the hub, and published to the distribution server for entitled users.

## Contributing

External contributions are welcome — open a PR against this repo. Keep changes within the plugin
(no new `stitch_backend` imports, keep the package self-contained). The vendored
`_vendor/rpc_server.py` is regenerated from the core SDK — do not edit it by hand.
